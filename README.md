# UrbanPulse

Urban intelligence for city comparison. UrbanPulse layers public air-quality exposure onto baseline livability rankings — so citizens and municipal decision-makers can see where headline scores and environmental risk diverge.

**Problem:** Rankings alone hide lived environmental conditions.  
**Approach:** One public dataset (Open-Meteo PM2.5), one clear data contract, one focused dashboard.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for data model, pipeline, and screen plan.
